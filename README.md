# Saret Narak — Creative Portfolio

Modern responsive portfolio website built with HTML, CSS and JavaScript.

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload all files and the `assets` folder from this project.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.

Your site will appear at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Customize

- Edit your text and email in `index.html`.
- Edit projects and skills in `script.js`.
- Edit colors and layout in `styles.css`.
- Replace `assets/saret-portrait.png` with another portrait if needed.
